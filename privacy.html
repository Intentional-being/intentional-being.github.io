Privacy Policy — Ankia Admin

Effective 7 October 2026.

Ankia Admin ("the app") is a private automation tool operated by a single individual ("the operator") for the operator's own Google account. It has exactly one user: the operator. This policy describes what data the app accesses and how it is handled.

1. What data the app accesses

With the operator's explicit consent, the app accesses the following data belonging to the operator's own Google account:

  • Gmail — message contents, headers, labels and settings, to classify, label and summarise the operator's own mail and to create filters that route recurring senders.
  • Google Calendar — event details, to read the operator's schedule and create events the operator asks for.
  • Google Drive, Docs and Sheets — files owned by the operator, to read and write the operator's own documents and spreadsheets.
  • Contacts (read-only) — the operator's own contact list, used solely to tell personal correspondence apart from bulk mail.

2. How the data is used

Data is used only to provide the functions described on the home page: daily mail triage, a daily digest sent to the operator, Gmail filter maintenance, research briefings assembled from public sources, and calendar management. The app takes no action on the operator's data that the operator has not configured or requested.

3. What the app does not do

  • It does not transfer Google user data to any third party.
  • It does not sell Google user data or use it for advertising, marketing, or profiling.
  • It does not use Google user data to determine creditworthiness or for lending purposes.
  • It does not allow any human other than the operator to read Google user data.
  • It is not used by any person other than the operator, and it serves no other users.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. How the data is stored and protected

OAuth credentials and any data derived from the operator's account are stored only on a private server controlled by the operator, protected by filesystem permissions, with encrypted transport (TLS) for all Google API calls. No Google user data is stored in a shared or public location, and none is published on this page or in any public repository.

5. Retention and deletion

Derived data is retained only as long as it is useful for the functions above. The operator can revoke the app's access to Google at any time at myaccount.google.com/permissions; revocation immediately ends all access, and stored credentials are deleted. Locally stored derived data can be deleted at any time by the operator, or by request to the contact address below.

6. Changes

Because this app has a single user, this policy is updated only when the app's data practices change. The effective date above always reflects the current version.
